## Deploy — this part was wrong and is now fixed

`deploy.sh` ran `npx prisma db push`, which reshapes the schema and **skips every
migration's data work**. Three steps in this history must run exactly once:

* `20260823000000` — reconciles historical تبديل التارجيت (without it, past
  conversions are handed back a second time)
* `20260823020000` — backfills each agency's self-charge counter (B10)
* `20260825000000` — seeds `gift_categories` (B4)

The script now runs `prisma migrate deploy`, and first marks the re-baselined
`0_init` as applied — a no-op on a fresh database, and required on the live one,
whose `_prisma_migrations` still holds the pre-baseline names and would
otherwise try to replay `0_init` over live tables. It then runs the poster
backfill.

**Back the database up before the first run of this script.**

### New migrations
* `20260826000000_profile_decor` — `users.profileDecorUrl` / `profileDecorType`
* `20260826010000_item_preview_url` — `items.previewUrl`

Both additive, both `IF NOT EXISTS`.
