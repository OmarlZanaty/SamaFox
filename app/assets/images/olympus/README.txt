Artwork for بوابات أوليمبوس (Gates of Olympus).

This directory is intentionally almost empty: the game ships playable with
painted placeholder symbols, a painted Zeus and a painted background, and
every one of them is replaced automatically the moment the matching PNG
lands here. Partial deliveries are safe — anything missing keeps its
painted fallback.

See OLYMPUS_ARTWORK_BRIEF.md at the repo root for the file list, the exact
names and sizes, and a generation prompt for each asset.
