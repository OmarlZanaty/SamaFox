## بناء التطبيق

- **Flutter 3.41.9 بالظبط.** ده الإصدار اللي اتبنت بيه 1.0.29، واتأكدنا منه من الـ engine hash `42d3d75a` جوه الـ APK.
  - Flutter 3.47 مش هيشتغل: مكتبة `livekit_client 2.6.4` مش بتتبني بيه، وكمان بيطلب Gradle 8.14 أو أحدث والمشروع شغال بـ 8.11.1.
- **الأدوات:** JDK 17، وAndroid SDK platform 36 مع build-tools 36.
- **الأمر:** من فولدر `app/`:
  ```bash
  flutter build apk --release --split-per-abi --target-platform android-arm64
  ```
  ولـ Play: `flutter build appbundle --release`.
- **رقم الإصدار:** رقم الـ APK بتاع arm64 = 2000 + رقم الـ build. يعني 1.0.30+2038 بيطلع 4038.
- **قبل أي إصدار جديد:** زوّد `version:` في `app/pubspec.yaml`.

## السيرفر

- **الجهاز:** Hetzner `apps-main` على `46.224.129.250`، والدومين `samafox.almobarmg.com` (قدامه Caddy).
- **الكود:** `/srv/samafox/backend`، وبيشتغل بـ pm2 تحت المستخدم `samafox`:
  - `PM2_HOME=/srv/samafox/.pm2`
  - اسم التطبيق `samafox-api`
  - البورت 3000
- **قاعدة البيانات:** Postgres في container اسمه `samafox-db`. بيانات الدخول في `/srv/samafox/stack/.env`.
- **SSH من جهاز جديد:**
  1. ضيف مفتاح SSH الجهاز الجديد لحسابك على GitHub.
  2. من كونسول Hetzner شغّل `ssh-import-id-gh omarlzanaty`.
- **الرفع:**
  1. type-check على نسخة تجريبية (`/srv/samafox/backend-staging-check`، والـ `node_modules` بتاعها link للي في `backend`).
  2. `tar` للملفات اللي هتتغير ومعاها `dist` ← `/srv/samafox/backups/`.
  3. فك الملفات الجديدة.
  4. `npx prisma migrate deploy && npx prisma generate`.
  5. `npm run build`.
  6. `pm2 restart samafox-api`.
- **آخر نسخ احتياطية:**
  - `deploy-20260925-0950-restore-main.tgz`
  - `db-before-cp-20260925-0002.sql.gz`: قاعدة البيانات كاملة قبل الـ CP.
- ⚠️ **درس اتعلمناه:** الـ `src` اللي على السيرفر كان أقدم من الـ `dist` اللي شغال. أول رفع يوم 24/9 عمل build من الـ src القديم، فوقّف هدايا الحظ وخصوصية الرسائل من 24/9 الساعة 11:49 لحد 25/9 الساعة 09:50. **ارفع دايمًا من فرع مبني على `main`، وقبل الرفع قارن `src` بالـ `dist` اللي شغال.**
